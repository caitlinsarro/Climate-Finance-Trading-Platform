# Eight-issuer model comparison chart pack

These figures are generated by `scripts/build_report_charts.py` from the same
governed model used by the local application. The script runs AAPL, CAT, CVX,
DE, DUK, MSFT, NEE and XOM at 2050 under five target/reference comparisons and
Low/Base/High conversion assumptions.

## Recommended report use

- `01_value_impact_range.png`: standalone Current Policies sensitivity plus its
  disclosed assumption range.
- `02_channel_attribution.png`: physical, transition and macro/supply value
  contributions for cross-issuer explanation.
- `03_scenario_value_heatmap.png`: direction and magnitude across alternative
  scenario questions. Colour is capped at ±100% for readability; cell labels
  retain uncapped results.
- `04_scenario_rank_stability.png`: whether relative issuer rankings survive a
  change in scenario. This is more decision-useful than treating one output as
  a price target.
- `05_reported_emissions.png`: reported Scope 1/2/3 evidence entering transition
  sensitivities.
- `06_physical_evidence.png`: issuer facility-match confidence. AAPL and MSFT
  remain explicitly unverified because their physical input is a FEMA fallback,
  not issuer-facility evidence.
- `07_duke_fcff_bridge.png`: DUK's reconciled 2050 reference terminal FCFF,
  three channel costs and target terminal FCFF before discounting.
- `08_net_zero_assumption_range.png`: Low/Base/High Net Zero sensitivity. A
  target enterprise-value floor is labelled as a boundary result, not hidden.
- `09_net_zero_channel_mix.png`: the physical, transition and macro/supply
  shares of absolute stress by issuer, useful for explaining why peers differ.
- `10_extreme_case_diagnostic.png`: terminal stress relative to reference
  terminal FCFF, separating ordinary sensitivities from cash-flow-floor and
  denominator-sensitive cases.
- `11_duke_data_provenance.png`: DUK's observed inputs, scenario paths,
  explicitly labelled demonstration assumptions and derived FCFF/enterprise-
  value outputs. It also states that equity and share-price impact are not
  calculable without a governed EV-to-equity bridge.

The underlying export is `reports/data/eight_issuer_scenario_results_2050.csv`.
The review workbook is `reports/Eight_Issuer_Climate_Stress_Test.xlsx`; its
formula-driven Checks sheet reconciles source rows, DUK's bridge, proxy labels
and boundary flags.
Missing inputs remain blank; they are not converted to zero. All outputs are
conditional prototype-demonstration sensitivities. Every chart footer identifies
non-observed calibrations as assumptions; outputs are not probabilities, price
targets, audited valuations or automatic investment decisions.
